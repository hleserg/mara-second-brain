# WhatsApp и SMS — сообщения с телефона

Спеки 8 и 9 по ТЗ «Mara Ambient Memory» (§13, §14, §5.1C, §5.1D; порядок §22
пункты 8–9). Одним куском, потому что обе трогают одни и те же пять файлов
Mara Capture, а каждая пересборка APK на doctor — минуты.
Предыдущие: [Mara Capture](2026-09-02-mara-capture-design.md),
[Telegram](2026-09-02-tdlib-design.md), [Gmail](2026-09-02-gmail-design.md).

## Зачем

Звонки и Telegram уже текут в contextd. WhatsApp и SMS — два оставшихся
канала, через которые люди договариваются с владельцем. Без них дайджест
обязательств видит половину разговоров.

## Что это НЕ делает

- Не читает WhatsApp никаким официальным или неофициальным API. Единственный
  честный источник на Android без root — уведомления (`NotificationListener`)
  плюс ручной «Экспорт чата» (ТЗ §13). Accessibility, скриншоты, web-скрейпинг
  — нет.
- Не становится SMS-приложением по умолчанию (ТЗ §5.1D). Читает
  `content://sms` с разрешением `READ_SMS`; откажет прошивка — падает на те же
  уведомления.
- Не хранит из уведомления ничего, кроме полей ТЗ §5.1C: пакет, время, кто,
  что, название беседы, признак группы, хеш ключа уведомления. Картинки,
  иконки, Person-URI и прочие extras не читаются вовсе.
- Не вызывает моделей. Телефон и импортёр только собирают; извлечение — на
  сервере, теми же очередями, что для Telegram.

## Дыры, которые надо признать (ТЗ §13)

- Уведомление не приходит, когда чат открыт на экране: такие сообщения
  видны только через экспорт.
- Своих исходящих из уведомлений почти нет: только ответ из шторки (у него
  нет отправителя в `MessagingStyle` — считаем своим). Остальное — экспорт.
- Медиа в уведомлении — заглушка («📷 Фото»), в экспорте — `<Медиа
  отсутствует>` или имя файла. Друг с другом они не дедуплицируются.
- Huawei убивает слушатель. При переподключении он перечитывает активные
  уведомления (`onListenerConnected`), но снятые за время смерти — потеряны.
- Переход SMS с уведомлений на провайдер: у двух путей разные ключи, окно
  перехода может дать дубли по тексту. Провайдер стартует от последнего
  SMS, пойманного уведомлением, чтобы окно было минимальным.

## Ключ сообщения — общий для телефона и импортёра

```
source_id = sha256(package | chat | sender | text' | floor(epoch_ms / 60000))
text' = trim + схлопнуть пробельные серии в один пробел
```

Минута целым числом эпохи, а не строкой локального времени: у Kotlin и Python
не может разойтись ни зона, ни формат. Unicode-нормализации нет — она у JVM и
Python разная. Фикс `tests/fixtures/whatsapp-message-id.json` сверяют обе
стороны: разъедутся — упадёт одна из них, и contextd перестанет отсеивать
дубли между уведомлением и экспортом.

SMS: `sha256("sms" | address | date | type | body)`. Не `_id` провайдера:
`dedupe_key` на сервере без устройства, и `_id=5` нового телефона столкнулся
бы с `_id=5` старого.

## Контракт события

Тот же `POST /v1/ingest/message`, что у Telegram. Сервер ставит `kind` сам.

```
{"source": "whatsapp", "source_id": "<sha256>", "occurred_at": "…+03:00",
 "classification": "personal",
 "payload": {"package": "com.whatsapp", "chat_title": "Семья", "chat_type": "group",
             "sender_name": "Анна Петрова", "text": "…", "outgoing": false,
             "via": "notification", "notification_key_hash": "<sha256>"}}

{"source": "sms", "source_id": "<sha256>", "occurred_at": "…",
 "classification": "personal",
 "payload": {"number": "+7999…", "contact_name": "Анна Петрова",
             "direction": "incoming", "text": "…", "via": "provider",
             "thread_id": 12, "read": true}}
```

`via` ∈ `notification | provider | export`. `contact_name` для SMS — из
`PhoneLookup` по одному номеру (ТЗ §5.1B), книгу целиком не выгружаем.
`cloud_allowed: false` в вольте выставляет сервер для всех сообщений, отдельно
слать нечего.

## Телефон

| Файл | Что добавилось |
|---|---|
| `Core.kt` | `Message`, `MessageId`, `NotificationParse`, `MessageJson`, `MessageFlow` — чистые |
| `Messages.kt` | `MessageListener : NotificationListenerService`; extras → значения → Core |
| `Device.kt` | `sms()` из провайдера, `contactName()` по номеру |
| `Store.kt` | таблица `messages`, схема 3, миграция **добавляющая** — `jobs` не сносим |
| `Sync.kt` | скан SMS + доставка сообщений после звонков |
| `Api.kt` | `postMessage` — тот же `post`, другой путь |
| `MainActivity` | строки здоровья, кнопка доступа к уведомлениям, `READ_SMS` в списке |

Слушатель отбрасывает сводки (`FLAG_GROUP_SUMMARY`), постоянные
(`FLAG_ONGOING_EVENT`) и уведомления без `EXTRA_MESSAGES` — у WhatsApp это
«проверяю сообщения» и «N новых» при выключенных превью, регэкспом по
локалям их не ловим. SMS-приложениям без `MessagingStyle` разрешён простой
`title + text`. WhatsApp на каждое новое сообщение перепостит последние
несколько — дедуп по ключу, `insert or ignore`.

Режимы SMS взаимоисключающие: есть `READ_SMS` — читаем провайдер, слушатель
SMS-пакеты игнорирует; нет — слушатель берёт их на себя. Мастер показывает,
какой режим действует.

## Импортёр экспорта

`scripts/whatsapp_import.py файл.txt|.zip [--chat Имя] [--me Я] [--dmy]`.
Форматы: Android RU `dd.MM.yy, HH:mm - Кто: текст`, Android EN `M/d/yy, h:mm
a - Who: text`, iOS `[dd.MM.yy, HH:mm:ss] Кто: текст`. Продолжения строк
клеятся к предыдущему сообщению. Строки без `Кто: ` — системные, пропускаются.
Название чата — из имени файла (`WhatsApp Chat with X`, `Чат WhatsApp с X`),
`--chat` перекрывает. Зона — системная, чтобы минута совпала с телефоном.

Токен — своё устройство `whatsapp-import`, файл `/etc/mara/whatsapp.env`.
Не telegram'овский: отзыв — на устройство.

## Как это тестируется без телефона

JVM: разбор уведомления (сводка/постоянное/без сообщений → пусто; группа;
свой ответ из шторки; SMS-приложение без стиля), общий фикс ключа, переходы
доставки. Python: тот же фикс, три формата экспорта, продолжения, системные
строки, zip, дедуп с уже посланным. Гейт как раньше: `./gradlew test` +
`assembleDebug` на doctor.

## Вопросы к утру

1. Дать Mara Capture доступ к уведомлениям (кнопка на экране → системный
   список) и разрешение SMS. Huawei: добавить в «защищённые».
2. Экспортировать чаты, которые важны, «без медиа», и прогнать импортёр.
   Какие именно — решает владелец; импортёр не гадает.
3. WhatsApp Business (`com.whatsapp.w4b`) слушаем тоже. Если его нет — ничего
   не происходит.
