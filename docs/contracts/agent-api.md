# Контракты agent-facing слоя

- Статус: действует с 2026-10-15 (Т6.3).
- Пункты ТЗ: §11 (read/query/correction, bounded payloads, timeouts,
  schema/version negotiation), §18 Фаза 5 п. 3.
- Опирается на: [ADR-0009](../adr/0009-mcp-authorization.md) — шлюза MCP
  нет, политика §11 действует на существующие поверхности;
  [ADR-0011](../adr/0011-widget-extension-boundary.md) — что такое контракт,
  как его называть и версионировать.
- Машинная копия — `tests/fixtures/agent-contracts.json`. Сервер сверяется с
  ней в `tests/test_agent_contracts.py`, плагин `install/mara-context`
  разбирает её примеры там же. Расходятся документ и фикстур — прав фикстур,
  а документ чинится.

## Общие правила

**Кто клиент.** Агент — Мара через плагин `mara-context` на маке. Шлюза MCP
нет (ADR-0009, решение 1): контракты — HTTP-роуты `contextd`, а инструменты
плагина — их обёртки. Когда шлюз появится, он отдаст те же контракты под
теми же именами.

**Транспорт и вход.** HTTP, JSON в UTF-8. Токен устройства — заголовком
`Authorization: Bearer …`. Токен узла (`--pair-node`) годится только для
сердцебиения и здесь получает 403.

**Права** (ADR-0009, правка решения 4). Со списком `scopes` читать пакет и
справку можно только с `memory:read` или `correction`, слать правку — только
с `correction`. Без списка (`null`) можно всё.

**Имя и версия.** Ответ называет свой контракт полем `contract` —
`mara.<область>.<имя>.v<N>`, по образцу ADR-0011. Правила — его решение 7:
- внутри версии поля только добавляются;
- убрать, переименовать или сменить тип поля — новая версия рядом.

Клиент знает имена, которые умеет разбирать. Чужое имя он не разбирает, а
говорит «обнови меня». Ответ без поля `contract` — doctor старше
контрактов, и его ответы считаются первой версией.

**Пределы.** Пагинации нет: каждый ответ ограничен по построению.
- Пакет `now` — до 2500 байт (`context_pack.MAX_BYTES`).
- Справка — до трёх пакетов по 15 пунктов; `about` — до 200 знаков.
- Правка: `item` — до 200 знаков, заметка — до 500. В ответе «не нашёл» —
  до 15 открытых заголовков и число остальных.
- Тело JSON — до 1 МиБ (`contextd.MAX_JSON`), длиннее — 413.

**Время.** Клиент ждёт пакет 2 с (`TIMEOUT`), справку и правку — 5 с. Поток
сервера ждёт тело запроса до 60 с (`Handler.timeout`).

**Недоверенный текст.** Заголовки обязательств — пересказ чужих слов из
разговоров. Во всех трёх ответах они идут с очисткой `context_pack.данные`
(Т0.9 п. 3): без знаков структуры пакета, кода карточки, невидимых
символов, не длиннее 90 знаков. Шапки текстов говорят модели, что это
данные, а не инструкции.

**Ошибки.** Тело ошибки — `{"error": "<текст для человека>"}`:
- 400 — запрос не по контракту, текст называет поле;
- 401 — токен не опознан;
- 403 — нет права;
- 413 — тело больше предела;
- 429 — подбор токена или больше правок в час, чем `MARA_CORRECTIONS_PER_HOUR`
  (`Retry-After`).

## `mara.context.now.v1` — пакет открытых обязательств

`GET /v1/context/bootstrap`; право `memory:read` (или `correction`).

Ответ:

| Поле | Тип | Что |
|---|---|---|
| `contract` | str | `mara.context.now.v1` |
| `now` | object \| null | пакет `now`; `null` — пакет не собран или пуст |
| `now.text` | str | текст для хода модели, между маркерами `<!-- mara:now -->` уже выделен |
| `now.sha256` | str | подпись содержания (ADR-0008, решение 2) |
| `now.supersedes` | str \| null | подпись пакета, который этот отменяет (решение 4) |
| `now.generated` | str \| null | время сборки |
| `now.items` | int \| null | сколько пунктов |
| `last_digest` | object \| null | последний доставленный дайджест звонка |
| `queue` | int | работ в очереди |
| `pipeline_version` | int | версия конвейера |

Свежесть — ADR-0008: пакет едет в ход, если его текста нет в истории сессии,
и старый называет устаревшим через `supersedes`. Каждое успешное чтение пишет
строку журнала `contextd` без содержимого.

## `mara.context.query.v1` — справка по человеку, проекту или слову

`POST /v1/context/query`; право `memory:read` (или `correction`).

Запрос: `{"about": "<имя в именительном падеже, проект или основа слова>"}`,
строка от 1 до 200 знаков.

Ответ:

| Поле | Тип | Что |
|---|---|---|
| `contract` | str | `mara.context.query.v1` |
| `about` | str | что спросили, очищенным |
| `generated_at` | str | время сборки |
| `sha256` | str | подпись содержания без минуты сборки |
| `ambiguous` | list | `person`, `project` — имя у нескольких в индексе |
| `packs` | list | опись: `pack_id`, `pack_type` (`person`, `project`, `query`), `items` (число), у проекта `conversations` |
| `text` | str | справка для модели — единственное, что идёт в ход |

Полей карточек в JSON нет — только в очищенном `text` (ADR-0008, правка
решения 1). Справка не кэшируется и не отменяется: это ответ на вопрос, а не
список на каждый ход.

## `mara.command.correction.v1` — правка обязательства словами

`POST /v1/ingest/event`; право `correction`. Единственная доменная команда
агента: шлюза нет, а прочих мутаций у агента нет (ADR-0009, решения 1 и 6).

Запрос:

| Поле | Тип | Что |
|---|---|---|
| `kind` | str | `correction` |
| `source` | str | `mara` |
| `source_id` | str | ключ повтора: плагин берёт хеш аргументов и минуту — повтор в ту же минуту даёт дубль, а не вторую правку |
| `occurred_at` | str, необязательно | когда сказано |
| `payload.item` | str | название обязательства, до 200 знаков |
| `payload.status` | str, необязательно | `open`, `done` или `cancelled` |
| `payload.due` | str, необязательно | срок `ГГГГ-ММ-ДД` |
| `payload.note` | str, необязательно | заметка в журнал карточки, до 500 знаков |
| `payload.id` | str, необязательно | код `#xxxxxxxx` из пакета или полный id |
| `payload.expected_version` | int, необязательно | версия, которую правка видела (ADR-0003) |

Нужен хотя бы один из `status`, `due`, `note`. Ключ повтора — поле
`idempotency_key` или заголовок `Idempotency-Key`, строка до 128 знаков (Т2.9):
повтор с тем же ключом получает тот же ответ с заголовком
`Idempotent-Replay: true`.

Ответ:

| Поле | Тип | Что |
|---|---|---|
| `contract` | str | `mara.command.correction.v1` |
| `event_id` | str | id события правки |
| `duplicate` | bool | такая правка уже была — повторно не применялась |
| `need_blob` | bool | у правки всегда `false` |
| `applied` | object \| null | итог; `null` у дубля |
| `applied.found` | bool | нашлась ли карточка |
| `applied.text` | str | итог словами — его Мара говорит владельцу |
| `applied.title` | str | заголовок, очищенный |
| `applied.id`, `applied.version` | str, int | адрес и версия для следующей правки |
| `applied.error` | str | `version_conflict` — карточка изменилась, правка не применена |
| `applied.ambiguous` | list | подходят несколько — уточнить |
| `applied.open`, `applied.open_more` | list, int | не нашёл: до 15 открытых заголовков и сколько ещё |
| `applied.created` | str | заведена новая задача (`status: open` без находки) |

Конфликт версий — нормальный ответ, не авария (ADR-0003, п. 4): правка не
применена, Мара переспрашивает владельца. Правка пересобирает пакет `now` до
ответа, так что следующий ход уже видит новый список.

## Чего здесь нет

- **Шлюза MCP** — ADR-0009, решение 1. Условие его постройки: первый
  инструмент записи сверх правки, который не выражается одним доменным
  роутом.
- **Подтверждений** — решение 6. У агента нет стирающих и шлющих наружу
  инструментов.
- **Контрактов панели** (`mara.report.*`, ADR-0011) — волна 8. Права
  `health:read`, `evidence:read`, `observatory:read` уже принимаются в
  список и ждут своих контрактов.
