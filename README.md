# mara-second-brain

Инфраструктура «второго мозга»: markdown-волт, который читается человеком в Obsidian,
служит памятью ассистенту Маре и даёт агентам контекст проектов.

**Это репозиторий инструментов, а не волта.** Волт — отдельный git-репозиторий на `doctor`
в `/srv/vault`, пушится только в bare-зеркало `/srv/backup/vault.git`. В GitHub он не уезжает
никогда: там `sensitive: true` и личный дневник.

ТЗ: [`docs/TZ.md`](docs/TZ.md).

## Топология

| Что | Где |
|---|---|
| Волт (source of truth) | `doctor:/srv/vault` |
| Bare-зеркало | `doctor:/srv/backup/vault.git` |
| Транспорт на устройства | Cloudflare R2, бакет `mara-vault` (Remotely Save / rclone) |
| Obsidian | Mac mini, Windows, телефон |
| Мара (Hermes) | Mac mini M1 |
| Тяжёлые батчи | GTR (WSL, GPU), по требованию |
| `beta-pi` | только разработка. Ничто в рантайме на неё не завязано (§13.6) |

## Установка на doctor

```bash
git clone git@github.com:hleserg/mara-second-brain.git ~/mara-second-brain
~/mara-second-brain/install/stage0-doctor.sh          # волт, git, зеркало, крон
~/mara-second-brain/install/basic-memory-doctor.sh    # Basic Memory + MCP
~/mara-second-brain/scripts/stage0-selftest.sh        # приёмка
```

Оба установщика идемпотентны. Креды R2 живут в `~/.config/rclone/rclone.conf`
на doctor и в репозиторий не попадают (ТЗ §11).

## Что крутится на doctor

| Что | Как |
|---|---|
| Синк с R2 | крон `*/5`, `scripts/vault-r2-sync.sh` (rclone bisync) |
| Автокоммит | крон `*/15`, `scripts/vault-git.sh commit` |
| Пуш в зеркало | крон `0 * * * *`, `scripts/vault-git.sh push` |
| Забор из старого бакета | крон `*/5`, `scripts/r2-legacy-pull.sh` — **временный**, до перецеливания устройств |
| Basic Memory MCP | systemd `basic-memory-mcp.service`, `127.0.0.1:8787` |
| Карточки пропущенных сессий | крон `20 * * * *`, `scripts/sessions-backfill.sh` |
| Реестр сущностей и линтер ссылок | крон `35 * * * *`, `scripts/entity-index.py --lint` |
| Дистилляция очереди | крон `40 * * * *`, `scripts/queue-worker.py` (venv с Presidio) |
| Коммиты за сутки | крон `10 3 * * *`, `scripts/git-ingest.py` (зеркала в `/srv/git-mirrors`) |

## Ingest сессий (этап 2)

```
Claude Code ──SessionEnd-хук──┐
                              ├─► спул ~/.local/state/mara/spool ──rsync──► волт
Codex ────────крон *:10───────┘        (он же очередь ретраев)
                                                │
                              kb/sessions/<id>.md + _system/queue/<id>.json
                                                │
                              крон *:40  queue-worker → редакция §8.3 → OpenRouter
                                                │
                              то же имя файла, distilled: true
```

**Карточка появляется сразу, без всякой LLM.** Заголовок, дата события, каталог,
счётчики, ссылка на сырьё — этого хватает, чтобы сессия нашлась поиском, и это
работает при мёртвой сети (§8.4, слой 2). Смысл сессии дописывает дистиллятор
позже, перезаписывая тело той же карточки.

| Машина | Что поставить |
|---|---|
| любая с Claude Code | `hooks/claude-session-end.sh` в `SessionEnd` в `~/.claude/settings.json` |
| любая с Codex | `scripts/codex-mirror.sh` по расписанию (у Codex хуков нет) |
| beta-pi, мак | systemd/launchd туннель `ssh -L 127.0.0.1:8787:127.0.0.1:8787 doctor` для MCP |

Клиент шлёт карточку не прямо в волт, а в локальный спул, и уже спул уезжает
`rsync`-ом. Нет сети — карточка лежит в спуле, следующий запуск хука доносит.
`rsync` пишет через временный файл и переименовывает, поэтому автокоммит (`*/15`)
и bisync (`*/5`) не поймают полузаписанный файл.

**Ключ дистиллятора:** `~/.config/mara/env` на doctor, `chmod 600`,
`OPENROUTER_API_KEY=...`. В волт и в репозиторий не попадает (§11). Без ключа
worker не падает, а держит очередь.

## Переезд на бакет `mara-vault` (1 сентября)

Старый бакет `obsidian-vault` заболел: 14 объектов из 184 перестали
перезаписываться и удаляться — `HTTP 500 InternalError` навсегда, ретраи не
помогают. Что измерено, а не предположено:

| Опыт | Результат |
|---|---|
| Принудительная перезапись всех 184 файлов волта, дважды | оба раза падают **одни и те же 14**, расхождений ноль |
| Здоровый ключ: запись → перезапись через 200 с → удаление | три раза `rc=0` |
| Пробный бакет: 40 объектов, перезапись через 5 мин, удаление | 0 ошибок |

Значит порча привязана к объектам, детерминирована и локальна для бакета —
поэтому переезд, а не ретраи. Волт остался нетронутым: он источник истины (§1),
бакет всего лишь транспорт (§2.1).

**Что нужно сделать на устройствах:** перецелить Remotely Save на телефоне,
маке и винде с `obsidian-vault` на `mara-vault`. Пока это не сделано, работает
`scripts/r2-legacy-pull.sh` — односторонний забор из старого бакета, чтобы
заметки, созданные на телефоне в переходный период, не потерялись. После
перецеливания удалить: строку из crontab, сам скрипт и
`config/r2-legacy-pull.txt`.

Старый бакет не удалён — в нём заперты 14 объектов, которые всё равно не
удаляются, и он же страховка на время перехода.

**Не гонять `scripts/stage0-selftest.sh` против старого бакета.** Он кладёт
файл в R2 и удаляет его в конце; в ту ночь именно так родились два лишних
испорченных ключа.

## Отступления от ТЗ и почему

**Строка в `daily/` (§6.5, §6.4) не пишется ни для сессий, ни для git.**
Это работа стороны дистилляции: строку есть из чего собрать только после
того, как модель вернула выжимку. Пока нет ключа OpenRouter, проверить
нечем, поэтому не написано — не забыто.


- **Remotely Save → rclone bisync.** Remotely Save это GUI-плагин Obsidian,
  на headless doctor его не запустить. Тот же бакет, исключения из §2.1
  в `config/r2-filters.txt`.
- **MCP на 8787, а не 8765.** 8765 на doctor занят docker-proxy контейнера
  `caddy-letheclaw`.
- **Свой rclone в `/opt/rclone`.** Системный 1.60 (2022), его `bisync`
  разваливается. Общий бинарь не трогаем — на нём чужие бэкапы.
- **Эмбеддинги Basic Memory через Ollama, не fastembed.** У fastembed из
  коробки `bge-small-en-v1.5` — английская модель на русско-английском волте.
  Провайдер переключён на litellm → `ollama/bge-m3`, 1024 измерения.
  Проверено: русский запрос «как настроить mqtt для умного дома» находит
  английские доки iot-stack.
- **Вьюхи Bases лежат в `views/`.** В §3 такой папки нет, а `_system/` — это
  служебное состояние, не пользовательский слой.
- **Структура §3 добавлена рядом с существующими папками волта**
  (`atman/`, `MeshCore/`, `Умный дом/`…), а не вместо них.
- **`Stop` как страховка не подключён.** §6.1 предлагает его вторым хуком, но
  `Stop` срабатывает каждый ход — это ssh-запись на каждую реплику. Ту же дыру
  (краш, сессия с мака, долгий оффлайн, вообще отсутствие хуков у Codex)
  закрывает `scripts/sessions-backfill.sh` на doctor: раз в час проходит по
  свежему сырью и делает недостающие карточки. Один сборщик вместо двух.
- **Имена людей не вычищаются перед отправкой в облако.** §8.3 требует
  PII-редакции, но §5 и §7 требуют, чтобы дистиллятор доставал людей и заводил
  карточки в `entities/people/`. Вырезав `PERSON`, мы ломаем этап 4. Режем то,
  что реально опасно: ключи, токены, приватные ключи, почту, телефоны, карты,
  IP. Список в `scripts/redact.py`, `PII_ENTITIES` — правится одной строкой.
- **Разовый прогон всей истории не делался.** `sessions-backfill.sh` смотрит
  сырьё за 3 суток. 508 старых сессий с мака лежат в `raw/` без карточек.
  Померено: дистилляция их всех — 0,6 млн токенов, около пяти центов, так что
  дорого не по деньгам, а по мусору в поиске. Решение за владельцем, issue #1.
- **Шаг 3 уборки волта переписан.** Прежний вывод «байт-в-байт не совпадает ни
  один файл» мерил фронтматтер Basic Memory и переписанные ` ```text `, а
  сравнивал с клоном репы, отставшим на 933 коммита. По-честному 45 файлов из
  64 — чистые копии репы. Разбор — `docs/vault-cleanup-step3.md`, считалка —
  `scripts/vault-vs-repo.py`.
- **Мак в этап 2 не входит: там нет Claude Code.** Проверено по ssh — ни
  бинаря, ни в PATH. Все 508 транскриптов оттуда уже на doctor, сверено
  пофайлово. Ставить хук не на что.
