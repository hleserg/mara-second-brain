# Репозитории для git-ingest (ТЗ §6.5). Формат: имя<TAB>own|fork
#
# Обновить (с любой машины, где есть gh — на doctor его нет, и не надо):
#   gh repo list hleserg --limit 200 --json name,isFork,diskUsage \
#     -q '.[]|select(.diskUsage < 500000)|[.name,(if .isFork then "fork" else "own" end)]|@tsv' \
#     | sort > config/git-repos.txt.new
#
# Отсечка 500 МБ выкидывает Momentum-Apps (1,2 ГБ) и all-the-plugins (570 МБ) —
# это апстримные сборники прошивок Flipper, своих коммитов там нет, а зеркалить
# два гигабайта чужой истории незачем.
#
# own — берём все коммиты: в своём репозитории и чужой коммит часть истории проекта.
